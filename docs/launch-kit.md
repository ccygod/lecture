# 发布文案

## 一句话介绍

Lecture：把大纲做成能讲、能听懂、能配页面的内容。

## 项目介绍

我开源了Lecture，一个面向中文讲课、客户汇报和公开发言的技能。它从用途和听众出发，把大纲加工成连续口播、逐页PPT制作说明和适合场合的配套框架，处理普通解释、案例、数据参照、转场与记忆落点。

仓库提供中文说明、原创前后对比、本地检查脚本和回归测试。结构、版本与数量可以检查，讲述分寸和现场效果仍需试讲验证。

https://github.com/ccygod/lecture

## 短帖

大纲有了，现场怎样讲？Lecture把听众、主张、口播和页面连起来。中文讲述技能现已开源，附示例和检查脚本，欢迎带着具体场景试用。
