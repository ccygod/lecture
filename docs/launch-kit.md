# Lecture launch kit

## One line

Turn an outline into a talk people can follow—and slide briefs that support it.

## 中文介绍

我开源了 Lecture，一个面向中文讲课、客户汇报和公开发言的 Agent Skill。它从用途和听众出发，把大纲加工成连续口播、逐页PPT制作说明和适合场合的配套框架；普通解释、案例、数据参照、转场与记忆落点放在一起处理。

仓库带中英双语说明、原创前后对比、本地检查脚本和回归测试。它能检查结构、版本与数量计算，讲述的分寸和效果仍需试讲验证。

https://github.com/ccygod/lecture

## English announcement

I’m releasing Lecture, an Agent Skill for Chinese teaching, briefings and talks. It connects audience intent, spoken explanation and per-slide production briefs, with source-aware editorial review and local checks. Includes original examples, bilingual docs and regression tests.

## Short post

A good outline still needs a voice. Lecture helps an AI agent build a continuous Chinese script and the slide briefs that carry it. Open source, examples included: https://github.com/ccygod/lecture
