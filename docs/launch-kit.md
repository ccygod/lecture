# 中文发布素材

这些文案可用于介绍项目；本次只保存素材，未向社区或社交平台发帖。

## 一句话介绍

Lecture：从具体困境讲起，让判断发生变化，让关键关系留下来。

## 项目介绍

一份大纲可以很完整，现场讲起来却仍然平。Lecture是一套面向中文授课、客户和领导汇报、公开发言的智能体技能，处理的正是大纲之后的编辑工作：保住讲者的主张，把关键案例走完，用关系类比解释术语，让轻松表达长在内容里，再将数字接到听众能做的选择。

例如，“计划要兼顾资源约束”可以讲成一张培训课表：两门课撞上同一间实训室；挪到下午，又遇到老师要去另一校区；继续改，直到教室、老师和路上的时间一起对上。听众看到判断怎样改变，讲者最后那句“约束对上才让人放心”也就有了依据。

页面随后接手，把这些关系摆到眼前：口播讲过程，上屏留关键主张，视觉呈现冲突与调整。仓库展示四组原创前后对比、一套口播到逐页视觉简报的完整样例，以及稳定页码、版本绑定评审、数量计算和184项回归测试。

当前8张编辑机制卡借鉴具体问题、选择叙事、使用体验与关系解释；罗永浩、雷军、王自如、混子曰是编辑参考，没有为项目背书。示例属于原创设计展示，现场效果仍需讲者试讲和听众反馈。

[查看项目与完整案例](https://github.com/ccygod/lecture)

## 短帖

我把Lecture的精华重新写进了首页：怎么让一个案例真正走完，怎么让类比解释关系，怎么让一句轻松的话服务知识，怎么让数字回答听众的“所以呢”。

这次附上四组中文前后对比和完整的“口播→逐字上屏→页面视觉简报”。还展示了保留讲者主张、整场回扣、扩页后的稳定引用与改稿后的版本评审。适合已经有内容、正在琢磨怎样讲出来的人。

[看示例](https://github.com/ccygod/lecture/tree/main/examples)
