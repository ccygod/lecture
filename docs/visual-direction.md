# 视觉方向：关系显影

用有秩序的几何关系表达判断的形成。散开的对象经由少量线索连成结构，留白成为等待与思考的空间。整幅图应让人先感受到推进，再读到名称；每一条连线都要承担具体含义。

颜色遵循信息职责：深色承托，暖白表达主体，橙色标出新条件，柔绿色提示关系已经对上。色彩不承担全部辨识，位置、描边与文字共同建立层级。用精细校准的对齐和线宽，让设计显出经过反复推敲的手工感。

尺度的变化对应认知重心。大的主张先落下，短小的标签跟随；重复几何只保留必要差异，让观众在同一视觉语法里看见条件发生了什么变化。字体与对象之间的距离需要像出版物一样逐处检查。

构图追求安静的张力，线索从左向右展开，最后的细节回望起点。精心制作体现在节奏、边距与比例，克制而不空泛。让每个保留的对象都经得起“删掉以后少了什么”的检查，以熟练工艺实现清楚的空间表达。
