# 1.0.2：把讲述的编辑方法写出来

这次更新集中在中文介绍、原创示例与发布素材，源码功能和现有安装保持原状。

首页从实际段落展示情境推进、判断反转、关系类比、内容相关幽默、受众价值桥、量感与口径。新增四组机制不同的前后对比，讲清普通解释、核心主张、记忆落点、整场节奏与回扣怎样连接。

新增完整“口播→逐字上屏→两页视觉简报”案例，涵盖认知动作、视觉论证、阅读顺序、讲者配合与误读验收。另附假设用时算例、稳定页码引用的可运行体验，以及版本绑定评审的实际边界。

更新原创中文封面和分享图，明确8张机制卡的编辑借鉴范围，保留来源与能力边界。本次没有生成PPT、调用昂贵模型接口或向外部社交平台发布。
