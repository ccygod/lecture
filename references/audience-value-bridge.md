# 把内容变成听众的切身价值

完整讲座、新稿关键数据、重要机制与学习建议使用。这里的受众关联性（personal relevance）与用途价值（utility value），回答“它为什么值得我现在花心思”。共鸣、好奇与继续听的意愿是可能结果，不是同一个设计动作，也不能靠加一句“与你有关”完成。

## 检查旧稿常见缺口

受众熟悉不等于切身相关；金额对照给量感，不自动给意义；幽默与反差也不自动说明值得学。数据页停在“规模多大、增长多少”，主张停在“行业很热”，机制停在“名词是什么”，都可能少了一步：听众正处在哪个任务或选择，内容改变了其中什么判断。

先问听众关心的实际任务、当前处境、未来节点或价值目标是什么。可以是学习、工作质量、资源、健康理解、家庭生活、社会责任、兴趣与身份，不能所有题材都套毕业、收入或就业。受众标签只是定位起点；关联必须有真实关系，不能凑。

## 最小关联链

关键位置记录：内容事实 → 受众锚点 → 作用机制/所需能力 → 后果或选择 → 一个可做的动作。先区分已有证据、条件推演和未知，再写口播。不是每段都走完整五步；一个主题可以共用一次关联，其余正常解释。

- 时间对齐：用明确入学年、学制、项目期限或生活节点计算；不知道时用有条件范围，不补造日期。
- 机会对齐：产业规模、招聘岗位、人才供给、薪酬和个人录用是不同变量。每跨一步都问依据；不能从营收增幅推岗位增长，也不能从岗位增长证明供给增速更慢。不同报告/地区/人群不拼接成全国确定缺口。还要查句子中的预设：问“供给比需求慢多少”已经把方向当成事实，缺证据时应先问两者怎样变化、是否匹配。此检查适用于成本、风险和收益比较，不只用于人才主题。
- 能力对齐：讲清谁可能受益、需要什么能力、听众有何准备窗口。不要把专家职位待遇当应届生起薪，也不要为了避开过度承诺把真实机会讲成全无意义。
- 行动对齐：保留一个听众目前能做的小动作，并让他自行判断与哪个个人目标有关。对专业新生，可以是找任务、做样例、核验结果或完成一段项目；对管理者或公众则按当次任务选。

把“企业可能争取这样的人”讲成有条件的愿景；“学完必定高薪、谁都会被抢”不是证据。可以有情绪与期待，但应当由机会、能力和准备的关系支撑。技术解释里的边界放在自然解释或备课说明，不让朗读正文每句话都变成免责声明。

## 实际接入程序

关键价值关联的位置，用 editor_workflow.py 的 need=connect_value，并填写 relevance：

```json
{
  "id":"value-1", "claim_id":"c1", "need":"connect_value",
  "relevance":{
    "audience_anchor":"当前受众的任务或时间节点",
    "content_fact":"已经核查的事实、预测或情境",
    "mechanism":"它为何影响这个任务，包含哪些能力或条件",
    "consequence":"听众可能面对的机会、代价或选择",
    "action":"听众现在可做的一步",
    "link_status":"conditional", "wording_strength":"conditional",
    "boundary":"此关联未证明哪些更强结论",
    "evidence":["材料定位，或尚缺哪项证据的明确记录"],
    "timeline":{"start_year":2026,"years":4,"target_year":2030}
  }
}
```

timeline按实际需要填写，上例只演示加法，不是所有受众的默认年级。程序检查链条字段、所声明证据状态与语气强度、年份运算；它不理解具体文字是否有关联，更不能核实劳动力缺口。候选审查需明确判断：这段能否回答受众的“所以呢”，推理有没有跳步。获选口播与页面一同进入原有交付契约，必须能找到真实正文，不能只留在JSON、映射或教学目标里。

## 语义复查与泛化

检查四种失败：只介绍听众已经熟悉的东西；只说宏观趋势很大；只套“这是你的机会”；用未核实的缺口/工资制造焦虑。正确关联允许直接讲，也允许反差与悬念。暂时想不到有价值关联时，说明原因并保留必要的知识解释，不造个个人利益来凑完整字段。

回归需包含学生的未来节点、管理者的项目期限、公众的日常任务，以及只需直接解释的段落；原文必须保留证据状态。评价“相关性提高”和“幽默更强”分别记录，不因为多次说“你”就认定有共鸣。

## 研究依据与采用边界

[Hulleman与Harackiewicz，Science 2009](https://sparq.stanford.edu/sites/g/files/sbiybj19021/files/media/file/hulleman_harackiewicz_2009_-_promoting_interest_performance_in_high_school_science_classes.pdf)：已读研究正文。262名高中生的学期实验中，学生主动写课程内容与生活的联系，对低成功预期群体的兴趣和表现更有帮助，高预期群体未见同样显著差异。采用“让听众自己建立用途联系、结合可完成的小动作”的原则；不能由此证明一场中国大学讲座讲职业前景就必然有效。
