# 口播回归与验证

修改口播规则、用户反馈整场不自然，或跨场景迁移时使用。普通短句修改不要求跑整套实验。

## 四项分别判断

1. **可说性：**句子是否需要讲者临场换词或重组才能说顺？指出具体句子及原因。
2. **单次可理解性：**听众能否跟上对象、逻辑和术语，听后复述关键关系？文本模拟只能发现疑点，不能证明听众实际听懂。
3. **继续听的理由：**信息是否持续推进；解释、例子、问题是否值得听；平讲也可以合格。没有Hook不自动扣分。
4. **保真与场合：**事实、数值、限定、责任与请求是否保留；正式程度是否适合讲者和听众。错误与虚构不能由风格得分抵消。

采用“可用 / 需改 / 证据不足”及具体片段说明，不汇总成伪精确自然度分。模型评价、讲者实际朗读、合成音频试听、真人听众反馈分别报告。

## 跨场景压力样例

| 场景 | 输入约束 | 观察点 |
| --- | --- | --- |
| 本科机制讲解 | 注意力结合其他位置的信息；token不固定等于汉字；权重不是因果解释；无公式、无现场提问 | 解释有可跟随的对象和过程，保留概念区别，不把大学生当幼儿 |
| 系统任务讲解 | 课表可能来自旧学期；Harness管理工具、状态、检查、停止；不能消除全部幻觉 | 定义能接上任务，不虚构本人经历或变成万能控制器 |
| 正式汇报 | 内部模拟100项任务：A成功90、B成功96；B自身复核从每项2变3分钟，A复核时间未知；未做显著性检验；请求批准试点 | 稳重直接，保留效果、代价及请求状态；不把B前后变化改成A/B差异，不强加互动 |
| 公众科普 | 本例降雨概率指指定地点时段可测降雨概率；30%不是时长；产品定义需查 | 易听懂而不失限定，不制造伪反转、不虚构统计 |
| 短收尾 | 已讲任务、材料、结果；交张老师实操，设备未知 | 简短接续，不再开新知识、不保证成功、不强制口号 |
| 整包教参 | 连续三个主题、既有PPT方式与时间；要求口播、映射和教学框架 | 字段压力下仍像讲话；普通解释不被强制改成预测题；试讲正文不混教学分析 |
| 规模参照 | 一个产业的未来预测规模，借已核对企业某年营收形成量感 | 有熟悉参照，明确不同口径年份，不当份额；算术正确，预测标签保留 |
| 中文幽默类比 | 内容相关、面向中国年轻人，参考混子曰和罗永浩的方法 | 不靠国外段子或热梗堆积；类比保留知识关系，不虚构个人经历；不笑也能接回解释 |

这些是测试材料，不是所有讲座的必讲主题或固定字数。可换领域保留同类约束。增加一个自然的原稿作为反例，检验是否越改越模板化。

## 比较方法

在相同原材料和交付约束下，比较无指导、旧规则、旧规则加笼统“口语化”提醒和新规则。优先使用隔离上下文；评审前隐藏版本名称并随机排列。不向试写者提供期望答案或其他组输出。

先检查原稿实际失败，再修最薄弱环节。跨案例单次试写是探索性检查，不是同一案例的重复实验；不能从五个不同案例推断稳定胜率。需要判断稳定性时，再对有分歧案例做独立重复，保留每份结果，不挑最好的一份展示。

自动化只检查确定性事实或结构。人工或模型可用具体片段标出疑点，但不能用句长、问号数、AI词频替代可说性和理解。控制样本已经自然时，应保留或小改；不要为了让新规则显得有效而扩大问题。

真人比较时可让同一讲者读随机版本，记录卡顿、临时改词及时间；听众不看文字，复述主要关系并说哪里没跟上，再评价自然度与继续听的意愿。合成音频尽量固定音色和语速，并分清合成问题与文稿问题。

## 验证记录

记录案例数、每案运行次数、各组使用的规则版本、评审者类型、失败片段和修正。结构脚本运行：

```bash
python3 scripts/test_check_output.py
python3 scripts/check_output.py <完整教参.md> --page-briefs
python3 scripts/check_output.py <纯口播.txt> --scope spoken
python3 scripts/test_compare_quantities.py
python3 scripts/compare_quantities.py <数据参照.json> --out <计算回执.json>
```

结构通过只说明未发现相应缺项或明确冲突。未实测就记录“未实际朗读 / 未真人试听 / 时长估算”；不得写“口播效果已验证”“所有测试证明更有吸引力”。
