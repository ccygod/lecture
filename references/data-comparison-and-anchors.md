# 重要数据的参照与量感

口播含重要规模、收益、风险或变化数字时读取。重要数字要让听众知道它处在什么量级，不能只念数值后说“很大”。这与反对空洞数字Hook并不冲突：参照帮助理解，Hook还需要新的判断或问题。

## 选参照

先问数字要说明什么，再选当前受众有认知基础的对象。优先同口径的基线、对照、历史值或同类规模；仍无法形成量感时，可以选择听众熟悉企业的年营收、日常时间或具体任务成本等参照。一个陌生数字不宜靠另一串更陌生的数字解释。不能把“知道一亿是什么”误当成“知道这个行业在经济里是什么量级”。

比较可有三种用途，必须区分：

- **同口径比较：**指标和统计期一致，用于直接比较不同对象。
- **趋势比较：**同一对象、同一指标的前后值。说明达到原来的多少倍、增加多少，不能混用；预测序列不成为实际增长。
- **量级参照：**借熟悉对象理解数量级。不同年份、统计对象或指标可以作明确标注的参照，但不能推导市场份额、收入相等、竞争关系或因果。年度流量不直接当存量，市值不直接当营收。

同一段的一组数字可以共用一个参照；不要求每个小数、样本数都配类比。参照已经清楚时直接说明差别；没有可信且合适的参照，说明缺口，优先保留同序列比值，不编一个熟悉对象的数据。用户明确要求“相当于XXX”时应主动寻找可信的外部参照，而不以“约12倍”代替全部量感解释。

量感不能替代结论依据。产业金额比一家企业营收小，只说明这次比较的金额关系，不能单凭它判断产业早期、成熟度或人才紧缺；这些判断另用对应证据与机制支撑。

## 写进口播和页面

通常将“原数值与口径—熟悉参照—近似关系—它说明什么”接在一起讲，顺序服从口播。保留预测、估算或教学假设标签。与结论有关的比较限定要说出来，不能全留在备注。

参考对象的准确值、年份、出处、计算和比喻边界放备课数据记录。PPT只呈现当前需要的比较，最多突出一个关系；用户要无来源页脚，出处留在教参，不删除年份、单位和预测标签。不要因口播借用生活类比而自动把整套PPT改成卡通。

### 本课示例 仅作已核对的参考 不固定复用小米

2025年报告预测全球具身智能市场195.25亿元人民币，2030年2326.3亿元：[转引报道](https://dzswgf.mofcom.gov.cn/news/phone/43/2025/4/m-1744782753327.html)。小米2024年营收3659.064亿元，取自其年报以百万元列示的365906.4：[年报](https://www.hkexnews.hk/listedco/listconews/sehk/2025/0424/2025042401119.pdf)，PDF第19页、印刷第17页。均核查于2026-10-13。

计算约为：195.25亿元是该营收的5.34%，约1/19；2326.3亿元是该营收的63.58%，口播可说“六成多”；两项市场预测相差约11.91倍，表述为“2030年预测值达到2025年预测值的约12倍”。

可讲：“拿大家熟悉的小米作个金额参照，它2024年一年的营收约3659亿元。195亿元，大约是它的十九分之一；2326亿元，也就是六成多。我们比较的是一个产业的预测规模和一家企业某年的实际营收，只帮助感受量级。它说明这个方向被寄予了增长期待，并不等于这张预测已经兑现。”

这些比值不是份额或行业竞争结论。小米只是本课候选参照，不是所有讲座的统一参照；是否熟悉仍按受众判断。更换参考年或公司时重新查原始资料，不沿用本示例数值。

## 让算术由程序完成

涉及单位归一、比例和倍数，使用 `scripts/compare_quantities.py` 的Decimal计算，不靠模型心算。先保存任务局部JSON：

```json
{
  "quantities": [
    {"id":"market","value":"195.25","unit":"亿元","metric":"市场规模","subject":"全球具身智能","period":"2025","status":"forecast","source":"已核对报告URL"},
    {"id":"anchor","value":"3659.064","unit":"亿元","metric":"企业营收","subject":"小米","period":"2024","status":"actual","source":"已核对年报URL"}
  ],
  "comparisons": [{"id":"scale","target":"market","reference":"anchor","purpose":"scale_reference"}]
}
```

```bash
python3 scripts/compare_quantities.py <数据参照.json> --out <计算回执.json>
```

purpose可选 `scale_reference`、`like_for_like`、`trend`；status可选 `actual`、`forecast`、`estimate`、`hypothetical`。已支持元/万元/亿元、美元相应单位、人数、时长、项数和百分比；不同币种不能暗中换算。不支持的单位先规范并记录换算依据，不能随意改标签。

脚本拒绝零分母、非数值、重复ID、不存在的引用及部分不可比组合，保留比较双方的事实状态。它只验证所输入记录的算术及显式条件，不能证明来源真实、参照适合听众或文字类比无误。生成像素中的数值也不由它保证。规则要求调用仍是skill层指引，不能宣称已有不可绕过的执行强制。
